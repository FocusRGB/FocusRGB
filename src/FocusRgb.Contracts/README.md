# FocusRgb.Contracts

Provider-neutral message and manifest types for the FocusRGB process-plugin protocol.

The language-neutral protocol and JSON schemas are the source of truth:
<https://github.com/FocusRGB/FocusRGB/blob/develop/docs/plugin-protocol.md>.

Contract 1.x keeps the proven provider status, catalog, apply, release, and lifecycle surfaces
stable. Minor releases may add optional, capability-gated behavior without breaking 1.0 plugins.
